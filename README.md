# 🚖 Uber Booking Analytics Dashboard | Power BI

An interactive **Power BI dashboard** developed to analyze Uber booking data and provide meaningful business insights through dynamic visualizations and key performance indicators (KPIs). The dashboard enables users to monitor booking trends, evaluate vehicle performance, analyze revenue, understand payment preferences, and track booking status through an intuitive and interactive interface.

## 💡 Key Insights

- Auto has the highest number of completed bookings.
- UPI is the most preferred payment method.
- Completed bookings contribute the majority of total rides.
- Booking demand remains consistent throughout the year.
- Payment methods contribute differently to overall revenue.
